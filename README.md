# Project Overview

## Task Manager CLI

### Features

- We can add tasks.
- We can update tasks.
- We can delete tasks.
- We can read a single task.
- Display List of tasks.
- Toggle status of task.(Complete, Pending).

### Task Data Type

- Unique id
- Task name
- Create datetime
- Update datetime
- Status

### Database

- data.json will be used to store tasks.
